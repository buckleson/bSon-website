## Bridges

Hyper 0X has one shared L1 bridge, and any L2 can also run its own. Bridge adapters connect to **EVM chains, Solana and Sui**: no lock-in, shared liquidity.

For example, a fintech moving USDC from Ethereum to pay exporters locks the USDC on Ethereum. Independent signers vouch for the lock before the same amount appears on Hyper 0X.

## SDKs

The Hyper Wallet SDKs let apps and games embed wallets and payments in hours, and reach other chains through Hyper 0X bridge adapters.

## Smart contracts

- **Languages:** Rust today, with a TypeScript framework in development.
- **Targets:** deploy to the L1 or any L2.
- **Governed upgrades:** the contract version hash is stored on the L1, and upgrades need approvals.
- **Policy annotations:** declare approval rules directly in code, for example `#[policy(approvals = "2-of-3")]`.

A typical example is export escrow: proof of shipping releases payment to the exporter, and if there is no proof by the deadline, the buyer is refunded automatically.

## Account abstraction

Users never handle seed phrases or gas tokens. One face scan to pay; the account enforces limits, the app can pay the fee, and a lost phone is not a lost wallet.
