Hyper 0X is the permissioned L1 blockchain that Buckleson built from scratch. Named institutions run its validators, and each customer gets its own L2 that settles to one shared L1. Each transaction is final in one pass, and every connection is post-quantum-resistant.

These docs explain each part of the chain for engineers and architects. Start with [What is Hyper 0X?](../guides/intro/) for the big picture, or go to [Getting started](../guides/getting-started/) to plan a pilot. For the commercial view, see the [Hyper 0X product page](../../products/hyper-0x/).
